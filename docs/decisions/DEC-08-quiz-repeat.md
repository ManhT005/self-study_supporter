# DEC-08 — Attempts per issued QuizSet

The Product Owner approved the proposed rule on 2026-11-08.

Accept one answer per question in each issued QuizSet. A replay with the same selection returns the existing result. A conflicting selection for an already answered question is rejected. To practice again, the learner starts a new QuizSet.

Allowing changes or multiple graded answers in the same QuizSet would require a separate grading and progress policy. The selected rule keeps one stable outcome per issued question. WP-04 defines the uniqueness constraint, and WP-05 verifies atomic grading and idempotent replay.
