LangChain ToolNode may internally format a Pydantic validation error with private
input. Middleware replaces error ToolMessages before the next model turn. Only
authorized retrieval objects populate citations. The adapter strips non-text
reasoning blocks and exposes no scratchpad/tool arguments in AgentResult.

The pinned Google SDK interprets retry attempts=0 as its default five attempts.
The bridge therefore sets the LangChain field `max_retries=1`, which is forwarded
as one total SDK attempt; a no-network test checks the actual SDK retry policy.
Request-owned native clients are closed on success/failure/cancellation, with a
bounded cleanup grace of one second. Execution deadline defaults to 45 seconds.

## Open acceptance gates

- Real Ollama/Gemini protocol, structured quiz, usage and cancellation observations
  have not been measured. The provider matrix marks them as candidates; a text
  adapter or unprobed/mismatched receipt is unavailable for native dispatch.
- Model aliases can move. Record exact provider revision/Ollama digest on a live
  run. A two-call protocol probe is not model-quality evidence.
- Note grants provide in-process idempotency only. Production writes need durable
  approval/idempotency and transactional deadlines. A synchronous committed write
  cannot be cancelled; fixture writes are intentionally bounded and inline.
- Reads may finish after cancellation, but cannot add late evidence or dispatch a
  later note. Production admission/rate controls are not broadened by this POC.
- LC-G1 still needs actual CI and reviewer signoff. G3, LC-G2, comparative adoption
  and production release remain open. No general prompt-injection robustness,
  citation support, real-provider quality or superiority is inferred.
